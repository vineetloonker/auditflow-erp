# Project: CA Practice Management System

Build a complete, modern, responsive **Chartered Accountant (CA) Firm Practice Management Software** using Laravel, MySQL, PHP, Blade, JavaScript and Bootstrap 5.

The software should help CA firms manage clients, GST filing, ITR filing, TDS, audit assignments, compliance deadlines, document collection, employee tasks, billing and client communication from one central dashboard.

The application must be fully functional, not just a UI prototype. All modules should have working CRUD operations, database relationships, validation, search, filters and reporting.

## 1. Design & Branding

Create a premium, minimalist and professional accounting software interface.

**Design direction:**
- Use a LIGHT THEME throughout the application.
- White and off-white backgrounds.
- Light blue, soft navy, muted teal and subtle sky-blue accents.
- Avoid dark backgrounds and overly saturated colours.
- Use a light CA-inspired colour palette.
- Clean typography with excellent readability.
- Rounded cards with subtle borders and shadows.
- Modern tables, charts and status indicators.
- Professional sidebar navigation.
- Responsive design for desktop, tablets and mobile.

**Logo:**
- Create a minimalist CA-inspired logo.
- Use a professional abstract combination of a document, financial growth and checkmark symbol.
- Keep the logo light, elegant and suitable for a Chartered Accountant firm.
- Do not use the official ICAI logo or imply ICAI endorsement.
- Display the logo in the sidebar and login screen.

## 2. User Roles & Permissions

Implement role-based access control.

1. Super Admin – Complete system access.
2. CA / Partner – Manage clients, compliance, audits, staff and reports.
3. Manager – Manage assigned clients and employee tasks.
4. Accountant / Employee – Access assigned work and clients.
5. Client – Limited portal access to upload documents, view requests, check filing status and download shared documents.

## 4. Client Management CRM

Build a complete client management module.

## 17. Technical Requirements

Technology stack:
- Backend: Laravel (latest stable version compatible with the deployment environment).
- Database: MySQL.
- Frontend: Blade templates.
- CSS: Bootstrap 5.
- JavaScript: Vanilla JS or lightweight libraries.
- Charts: Chart.js.
- Icons: Lucide or Bootstrap Icons.
- PDF generation for invoices and reports.
- Authentication with secure password hashing.
- Role-based permissions.
- Laravel validation.
- CSRF protection.
- Secure file storage.
- Database migrations and seeders.

Architecture:
- Follow MVC architecture.
- Use reusable Blade components.
- Use service classes for business logic.
- Use database transactions where necessary.
- Use Eloquent relationships.
- Use pagination on large datasets.
- Add search and filters to all major listing pages.
- Implement audit logs for important activities.
- Use proper access control and tenant/client data isolation.

## 18. Important Development Instructions

1. First inspect the project directory and existing environment.
2. Create the complete database schema and migrations.
3. Build authentication and role-based access.
4. Develop the dashboard and sidebar.
5. Develop each module with functional CRUD operations.
6. Implement database relationships.
7. Implement client portal access.
8. Add realistic demo data for testing.
9. Test all forms, buttons, filters and workflows.
10. Fix all errors before considering the application complete.

Do not build a static dashboard with dummy buttons.

Every navigation item must open a functional page. Every form must save data to MySQL. Every listing must display actual database records.

Create a professional, polished, production-oriented CA Practice Management System that can be demonstrated to real Chartered Accountant firms.

**Final objective:** A complete CA Firm ERP that allows a Chartered Accountant to manage clients, compliance, documents, employees, deadlines, audits and billing from one unified platform.
